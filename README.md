منصة إلكترونية متكاملة لإدارة وحجز المواعيد الطبية في الجزائر، مخصصة للمرضى والأطباء مع لوحة تحكم إدارية متعددة المستويات.

---

## 🌟 الميزات الرئيسية (Features)

### 👤 للمرضى (Patients)
- **حجز سهل وسريع:** حجز المواعيد وفقاً للتقسيم الإداري الجزائري (الولاية ← الدائرة ← البلدية).
- **تصنيف الأطباء:** البحث حسب التخصص (طبيب عام أو طبيب أخصائي) مع إمكانية البحث بالاسم.
- **نظام طابور ذكي:** حجز الموعد تلقائياً في أول يوم عمل متاح للطبيب مع إصدار رقم دور تسلسلي (Queue Number).
- **وصل حجز رقمي:** توليد وصل رقمي قابل للتحميل كصورة (PNG) لإبرازه عند زيارة العيادة.
- **تتبع الحجوزات:** البحث عن المواعيد المحجوزة مسبقاً باستخدام رقم الهاتف.

### 🩺 للأطباء (Doctors)
- **تسجيل حساب جديد:** معالج تسجيل من 3 مراحل (بيانات الحساب ← الموقع ← التخصص) مع فترة تجريبية مجانية لمدة شهر.
- **لوحة تحكم تفاعلية:** جدول مواعيد مصنف حسب الأيام (أمس / اليوم / الغد / الكل) مع خاصية البحث.
- **إدارة جدول العمل:** التحكم بالحد الأقصى للمرضى يومياً، وتفعيل/تعطيل أيام العمل بشكل منفصل.
- **التحكم في الحجوزات:** تفعيل أو إيقاف استقبال الحجوزات الجديدة بزر واحد.
- **نظام الاشتراكات:** تجديد الاشتراك عبر رموز تفعيل (Activation Codes) لمدد 3، 6، أو 12 شهراً.
- **علامة التوثيق:** شارة توثيق (✔ Verified) تُمنح من قِبَل الإدارة للأطباء الموثوقين.

### 🛡️ للمشرف / CEO (Admin Panel)
- **بوابة إدارية آمنة:** محمية بكلمة سر مشفرة وجلسات قصيرة الأجل (JWT).
- **إدارة الأطباء:** البحث عن الأطباء وتعديل بياناتهم وتوثيق حساباتهم أو حذفها وإعادة تعيين كلمات المرور.
- **إدارة الفريق الإداري:** إنشاء حسابات موظفين بأدوار متعددة (Deputy CEO / Officials / Managers / Employees) مع تخصيص صلاحيات (التوثيق، الاشتراكات، البيانات الشخصية).
- **إدارة رموز الاشتراك:** توليد رموز تفعيل فريدة (16 حرفاً) لمدد مختلفة ومتابعة الرموز المستخدمة.
- **تمديد الاشتراكات:** تمديد اشتراك أي طبيب مباشرة بـ 1، 3، 6، أو 12 شهراً.

## 🏗️ التقنيات المستخدمة (Tech Stack)

| الطبقة | التقنية |
|--------|---------|
| **الواجهة الأمامية** | HTML5, CSS3, Vanilla JavaScript |
| **الخادم (Backend)** | Node.js + Express.js |
| **قاعدة البيانات** | Supabase (PostgreSQL) |
| **المصادقة** | JWT (JSON Web Tokens) + bcryptjs |
| **الحماية** | express-rate-limit, CORS |
| **التوليف المرئي** | html2canvas (لتصدير وصل الحجز كصورة) |
