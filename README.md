# TabibDZ - نظام إدارة وحجز المواعيد الطبية 🇩🇿

منصة إلكترونية متكاملة لإدارة وحجز المواعيد الطبية في الجزائر، مخصصة للمرضى والأطباء مع لوحة تحكم إدارية.

---

## 🌟 الميزات الرئيسية (Features)

### 1. للمرضى (Patients)
- **حجز سهل وسريع:** حجز المواعيد وفقاً للتقسيم الإداري الجزائري (الولاية -> الدائرة -> البلدية).
- **تصنيف الأطباء:** إمكانية البحث حسب التخصص (طبيب عام أو طبيب أخصائي).
- **نظام طابور ذكي:** حجز الموعد تلقائياً في أول يوم عمل متاح للطبيب مع إصدار رقم دور تسلسلي (Queue Number).
- **وصل حجز رقمي قابل للتنزيل:** توليد وصل رقمي يمكن تحميله مباشرة كصورة (PNG) لإبرازه عند زيارة العيادة.

### 2. للأطباء (Doctors)
- **تسجيل حساب جديد:** معالج تسجيل من 3 مراحل مع فترة تجريبية مجانية لمدة شهر (Free Trial).
- **إدارة المواعيد:** جدول تفاعلي للمواعيد مصنف حسب الأيام (الأمس، اليوم، الغد) مع إمكانية البحث بالاسم ورقم الهاتف.
- **تخصيص جدول العمل:** التحكم بالحد الأقصى للمرضى يومياً، وتحديد ساعات الدوام لكل يوم من أيام الأسبوع بشكل منفصل.
- **نظام الاشتراكات:** تجديد الاشتراك عبر رموز التفعيل (Activation Codes) لمدد 3، 6، أو 12 شهراً.

### 3. للمشرف (Admin)
- **بوابة إدارية آمنة:** محمية بكلمة سر مشفرة وجلسات قصيرة الأجل.
- **إدارة الأطباء:** البحث عن الأطباء وتعديل بياناتهم وتوثيق الحسابات (Verified Badge) وإعادة تعيين كلمات المرور أو حذف الحسابات.
